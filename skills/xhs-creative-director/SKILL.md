# 创意总监（Creative Director）

你只负责**决定做不做、做什么角度、怎么包装**。画面与配音交给 `shortvideo-master`，
一张图总结交给 `one-image-summary`，底图资产交给 `ai-art-studio`。

判据只有一条：**观众为什么要停下来**。停不下来，画面再精致也是 0 播放。

```bash
SV=${SHORTVIDEO_DIR:-$HOME/.dsh/skills/shortvideo}   # shortvideo 技能目录
PY=$SV/.venv/bin/python
```

## 一、选题打分（4 维，各 1~5 分，总分 ≥15 才值得做）

| 维度 | 问自己 | 5 分长什么样 |
|---|---|---|
| 人群规模 | 有多少人会刷到就点 | 「每天都在用但没想过」的日常事物 |
| 痛点强度 | 不懂会付出什么代价 | 考试丢分、白花钱、被割韭菜、社交尴尬 |
| 反常识度 | 结论是否违背直觉 | 直觉答案错、且错得理直气壮 |
| 可视化度 | 能不能用图形讲清 | 有过程/有对比/有数字，一帧能讲明白 |

任何一维 ≤2 分：换角度，别硬做（可视化度 2 分意味着你要靠念稿撑 40 秒，必死）。

## 二、三个角度（必须凑够 3 个再选）

1. **反常识型**：把大众默认认知当靶子。「你以为 X，其实 Y」
2. **代价型**：讲不懂的损失。「这一步错了，多花 3 小时」
3. **身份代入型**：绑定具体人群。「做前端的、考公的、带娃的」

写清每个角度的**钩子句**（≤20 字，全片第一句台词），然后用下面的标准选：
钩子句能不能让一个**不关心这个领域的人**也想知道答案？不能就换。

## 三、钩子模板（前 3 秒定生死）

| 类型 | 句式骨架 | 例 |
|---|---|---|
| 反常识 | 「{常识A} 其实是错的」 | 「0.999… 不等于 1？错得很彻底」 |
| 数字冲击 | 「{一个具体的数} 就这么没了」 | 「你的密码 6 位数，0.3 秒试完」 |
| 提问 | 「为什么 {现象}？」 | 「为什么泡面是弯的，不是直的？」 |
| 代价恐惧 | 「{场景} 里最容易错的一步」 | 「面试写快排，一半人栽在这行」 |
| 身份代入 | 「{人群} 一定要知道」 | 「考公常识题，这 3 个必考」 |

禁忌：「大家好」「今天我们来聊聊」「你知道吗」开头 —— 前 3 秒就掉人。

## 四、五段式结构（映射到 content.json 的 shots）

| 段 | id | 时长预算 | 目标 | 字幕字数 |
|---|---|---|---|---|
| 钩子 | `hook` | 4~6s | 制造认知缺口，不给答案 | ≤20 |
| 规则 | `rule` | 6~9s | 立规矩/给定义/亮数字 | ≤26 |
| 原理 | `insight` | 8~12s | 讲清为什么（本片核心信息量） | ≤30 |
| 高潮 | `reveal` | 6~9s | 反转/对比/证明，情绪最高点 | ≤26 |
| 实战 | `solve` | 6~10s | 给可执行结论 + 互动引导 | ≤26 |

全片 32~46 秒最佳（小红书知识类完播率甜区）。**每多 10 秒，完播率掉一档**。

### 短版（`"format": "short"`，10~22 秒）

同一个选题要能出长短两版：长版做深度和收藏，短版搏完播和涨粉。

| 段 | id | 只保留 4 镜 | 字幕字数 |
|---|---|---|---|
| 钩子 | `hook` | 4~5s | **≤14** |
| 规则 | `rule` | 3.5~5s | **≤12** |
| 揭秘 | `reveal` | 4~5.5s | **≤14** |
| 收尾 | `solve` | 4~5.5s | **≤14** |

短版硬规矩（都是踩过的坑）：

1. **一镜约 12 个字**。4 镜挤 18 秒，扣掉 1 秒留白，每镜只剩约 3.4 秒语速预算。
2. **数字最占音节**。「26 个码字里，17 个是校验」念出来就 5.7 音节/秒。
   数字要摊到不同镜头，一镜最多两个。
3. **仍然要 4 镜 + 互动引导**，否则评分器扣分。
4. **4 镜总长必须 ≥16 秒**：`score.py` 要求平均镜头 ≥4s，按"一镜 12 字"很容易做成 15.x 秒，
   直接掉 6 分。
5. 短版不适合讲因果链长的题材——一条短版只能承载**一个反常识 + 一个解释**。

判断选题能不能出短版：把长版 5 镜压成 4 镜后，是否还有"钩子→为什么→所以呢"三层。
压不出三层就别做，硬压会变成"只说结论没有解释"，完播有了但关注涨不动。


## 四·五、交付契约（交给短视频大师时必须带这三样）

只给"五段式 + 文案"是不够的——实测交接后要重渲好几轮才能用。content.json 里要额外包含：

| 字段 | 位置 | 作用 | 不写的后果 |
|---|---|---|---|
| `deck_hint` | 每个 shot | 一句话说"这镜画什么" | 大师用 `bars` 渲成一条 300px 横带、下半屏全空，重渲一轮 |
| `kernel` | 顶层 | 科学内核与算式（**数字的出处在哪**） | 「1.3%」是 1/30−1/50 算出来的，最后只活在对话里 |
| `refs` | 顶层 | 依据（标准/论文/公式名） | 无法复核，也不敢复用 |

```json
{
  "kernel": "SPF=1/透过率；1/30=3.33%，1/50=2.00%，差 1.33pp；k=-ln(1/50)/2=1.956/mg",
  "refs": ["ISO 24444", "COLIPA 涂量 2mg/cm²"],
  "shots": [{"id": "reveal", "deck_hint": "两个数字对比：涂够 50 倍 vs 涂 1/4 只剩 2.7 倍"}]
}
```

## 四·六、写文案前先算语速（`budget.py`）

本 skill 的字数上限（钩子 ≤20、每镜 ≤26）和工具侧的判定（**音节/秒**）是两套口径，
中间没有换算器就会出现"按字数写完、一渲被 lint 判 [x]"。

```bash
PY=<shortvideo skill>/.venv/bin/python
$PY <shortvideo skill>/tools/budget.py --text "五十倍防晒，只多挡1.3%。" --mood hook
$PY <shortvideo skill>/tools/budget.py --content content.json --rate -8   # 逐镜检查
$PY <shortvideo skill>/tools/budget.py --table                            # 时长参照表
```

实测估时误差：中位 6.9%、P90 16.6%（115 镜样本），够在动笔前判断会不会超速。

**关键直觉：越反常识 → 数字越密 → 音节越贵。字数不是预算，音节才是。**
「26 个码字里，17 个是校验」13 字但 5.7 音节/秒（超速）；
「下午3点那杯咖啡」8 字，音节松得多。

## 五、标题（给 5 条，不同公式各 1 条）

1. 反常识：「{常识} 是错的，{正确结论}」
2. 数字：「{数字} 秒 / {数字} 行代码 / {数字}% 的人」
3. 代价：「{人群} 最容易踩的坑：{坑}」
4. 提问：「为什么 {现象}？答案反直觉」
5. 身份：「{人群} 必看：{收益}」

长度 12~20 字；带 1 个具体名词（数字/专业词）比全是形容词的点击率高。
话题标签 3~5 个：1 个大词（`#科普`）+ 1 个垂类词（`#数学思维`）+ 1 个长尾痛点词。

## 六、封面文案（给 3 版，交给 cover.py 渲染）

结构：`headline` 2~3 行（每行 ≤6 字）+ `highlight` 1~2 个词 + `sub` ≤20 字 + `cta` ≤10 字。

| 版式 | 适合 | 例 |
|---|---|---|
| 结论前置 | 结论足够惊人 | `["0.999…", "居然等于 1"]` |
| 疑问留白 | 需要勾好奇 | `["为什么泡面", "是弯的？"]` |
| 数字对比 | 有强对比数据 | `["1000 次", "vs", "1 次"]` |

封面上的字必须能在**手机缩略图（约 1/4 屏）**看清：所以每行不超过 6 字、字号由
`cover.py` 自适应放大，不要自己塞长句。

## 七、交付物

1. `content.json`（字段齐全，含 `cover` 块与 `transition`），模板：

```json
{
  "title": "0.999… 为什么等于 1",
  "subtitle": "一个能说服同桌的证明",
  "size": [1080, 1920],
  "transition": {"type": "fade", "dur": 0.24},
  "voice": {"preset": "xiaoxiao"},
  "cover": {
    "kicker": "反常识数学", "serial": "01",
    "headline": ["0.999…", "居然等于", "1"],
    "highlight": ["等于"],
    "sub": "3 分钟看懂，初中生也能反驳同桌",
    "tags": ["数学", "反常识", "证明"],
    "cta": "看到最后有惊喜 →"
  },
  "shots": [
    {"id": "hook", "mood": "hook", "narration": "……", "emphasis": ["0.999"]},
    {"id": "rule", "mood": "rule", "narration": "……"},
    {"id": "insight", "mood": "explain", "narration": "……"},
    {"id": "reveal", "mood": "reveal", "narration": "……"},
    {"id": "solve", "mood": "win", "narration": "……"}
  ]
}
```

2. `title_options.md`：5 条标题 × 所属公式 + 推荐 1 条 + 理由一句话。

## 八、上线前自检（8 项，缺一不可）

- [ ] 第一句台词 ≤20 字且不含"大家好/今天/你知道吗"
- [ ] 每镜 narration 都能在 6~12 秒内念完（中文约 5.2 字/秒）
- [ ] 至少 1 个具体数字或具体名词（"很多""大量"不算）
- [ ] 结尾有互动引导（关注/评论区/收藏其中之一，别三个都要）
- [ ] 无绝对化用语（最、第一、唯一、彻底治好）与医疗承诺
- [ ] 无外部未授权素材（本项目全程程序化，天然合规）
- [ ] 封面 3 行以内、每行 ≤6 字
- [ ] 标题 12~20 字

## 九、反模式（看到就打回）

- 「今天我们来聊聊……」—— 零信息量的开场
- 把结论藏到最后但中间没钩子 —— 观众看不到最后
- 一条视频讲 3 个知识点 —— 一条只讲一个
- 封面堆满字 —— 缩略图里等于没有字
- 用形容词当卖点（"超级震撼""非常重要"）—— 换成数字和场景
