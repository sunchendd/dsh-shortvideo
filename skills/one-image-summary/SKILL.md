# 一张图总结大师（One-Image Summary）

规矩只有一条：**一张图只讲一件事**。塞两个知识点，等于两个都没讲。

```bash
SV=${SHORTVIDEO_DIR:-$HOME/.dsh/skills/shortvideo}
PY=$SV/.venv/bin/python
$PY $SV/tools/oneimage.py --spec spec.json --out out/summary.png
$PY $SV/tools/art.py --list            # 底图风格 / 配色
```

## 一、先定"记忆锚点"，再写要点

1. 用一句话（≤18 字）说出读者**明天还会记得的那句话** —— 这就是 `big.value`。
   例：`0.999… = 1`、`交换次数少一半，速度就差一倍`、`泡面弯是为了不洒汤`。
2. 再倒推 4~6 个支撑它的要点，每点回答"为什么"或"所以呢"。
3. 写不出来 3 个要点 = 这个知识点不适合做一张图（改成分镜视频）。

## 二、文案硬约束（写超了就是在浪费版面）

| 字段 | 上限 | 说明 |
|---|---|---|
| `title` | 2 行，每行 ≤7 字 | 大字，决定点击 |
| `highlight` | 1~2 个词 | 标题里的关键词，用高亮色块压住 |
| `points[].t` | ≤14 字 | 要点主句（大字） |
| `points[].d` | ≤22 字 | 解释（小字，可省略） |
| `big.value` | ≤14 字 | 记忆锚点（公式/结论） |
| `big.label` | ≤20 字 | 给锚点的一句话注脚 |
| `tags` | 3~4 个 | 2~5 字/个 |
| `footer` | ≤24 字 | 账号署名 + 一句定位 |

要点之间的逻辑：**递进或并列，不要混**。混了读者就抓不到结构。
推荐三种结构：`定义→为什么→反例→结论`、`三个误区→正确做法`、`现象→机制→应用`。

## 三、spec.json 模板

```json
{
  "kicker": "反常识数学",
  "title": ["0.999…", "为什么等于 1"],
  "highlight": ["等于 1"],
  "points": [
    {"t": "它是无限小数", "d": "0.999… 后面不是停在某一位"},
    {"t": "差值只能是 0", "d": "1 - 0.999… 比任何正数都小"},
    {"t": "极限的定义", "d": "无限逼近即相等，没有差一点"},
    {"t": "换个算法验证", "d": "0.999… × 10 - 0.999… = 9"}
  ],
  "big": {"value": "0.999… = 1", "label": "在实数系里，它们就是同一个数"},
  "tags": ["数学", "反常识", "证明"],
  "footer": "@你的账号 · 每天一个反常识",
  "style": "mesh",
  "seed": 3
}
```

可选：`style`（mesh/aurora/rays/grid/paper）、`palette`（default/cool/warm/paper）、`accent`（`[R,G,B]`）。

## 四、从视频稿提炼（别重写）

1. 取每镜 `narration` 的第一句 → 就是天然要点（视频稿本来就是"一句一镜"）
2. 去掉口语连接词（"那么""其实""你会发现"）
3. 把数字/结论提到句首
4. `big.value` 优先用**公式或等价式**，没有公式就用"数字对比"（`差 2 倍`）

## 五、验收清单

- [ ] 手机缩略图（约 1/4 屏）里能读清标题
- [ ] 要点 ≤6 条，每条 ≤14 字
- [ ] 有且只有一个"记忆锚点"
- [ ] 没有豆腐块（`R.sanitize` 已兜底，但别写生僻符号）
- [ ] 底图不抢字：文字区域对比度足够（深底浅字 / 浅底深字）
- [ ] 标签 3~4 个，含 1 个大词

## 六、配套产出（做视频时一起交付）

- 视频末帧可以放这张图的缩略版（一帧静帧），把流量导到图文笔记
- 封面用 `cover.py`（3:4 三版式），信息图用 `oneimage.py`（单张），两者比例一致都是 3:4
