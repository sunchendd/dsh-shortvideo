# 小红书爆款科普竖屏短视频 Playbook

> 目标：把本仓库的 `shortvideo` 插件（`content.json` → edge-tts 配音 → Pillow 逐帧 → ffmpeg）调成「小红书能爆」的形态。
> 本文所有条目都写成**可直接落到代码里的参数**：`content.json` 字段、`SceneAPI.caption()` 参数、封面 Pillow 绘制参数、标题/话题字符串。
> 引用规则：每条结论后面给来源链接；找不到一手来源的社区经验，明确标注**「经验值，未经证实」**。
> 抓取时间：2026-10。所有抓取内容仅作数据使用。

---

## 0. 平台机制：先搞清「爆」的判定变量

| 变量 | 公开阈值 | 来源 |
|---|---|---|
| 首池曝光 200–500 的晋级线 | 点击率 ≥ **8%**、互动率 ≥ **5%**、完播率 ≥ **45%** | [小红书流量机制全解析（2026新版）](https://3g.163.com/news/article/KIMU57Q405566M9N.html) |
| 第二池 5000–2万 的晋级线 | CES 达标 + **收藏率 ≥ 3%** + 评论质量 | 同上 |
| 第三池 10万–500万 | 转化率 > 2% | 同上 |
| CES（互动分）公式 | 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×**8** | 同上 |
| 流量结构 | 推荐（发现页）≈60%，搜索 **30%–65%**，社交 ≈10% | 同上 |
| 掉池规则 | 连续 3 天数据下降 30% 可能停止推荐 | 同上 |
| 首 3 秒 | 超过 **70%** 用户在前 3 秒决定是否继续看；开头应压在 **3–5 秒**内直入主题 | [小红书爆款视频开头怎么做（有赞）](https://www.youzan.com/cms/article/69295.html) |
| 开头 2–5 秒 + 封面决定爆率 | 跳出率 > **50%** 基本不可能爆；95% 的爆款开头在复用少数几个结构 | [拆解1000个爆款视频后，我总结了10个爆款开头](http://m.163.com/dy/article/KDI21NH80544FV67.html) |
| 口播语速基准 | 普通话 **240–260 字/分钟**（= 4.0–4.33 字/秒）；慢速 220–240 | [如何从源头控制文案长度](https://www.sohu.com/a/1091026412_121488262) |
| 竖版推荐时长 | **30–90 秒**；60 秒 ≈ 240–260 字；90 秒 ≤ 390 字 | 同上 |
| 画幅 | 支持 16:9 与 9:16；竖屏 1080×1920 | [小红书视频剪辑比例及技巧](https://m.sohu.com/a/788436931_121894855/) |

**对我们最重要的一条结论（可直接改代码）**：`content.json` 里 `min_dur` 不该凭感觉写，应满足
`min_dur ≥ 字数 / 4.2`（4.2 字/秒 取 240–260 区间的中值偏快，适配 hook/win 的加速韵律）。
现仓库范例 `sorting.content.json` 的 hook 是 **28 字 / 5.2 s（≈5.4 字/秒）**，比 240–260 字/分的上限高约 **25%**；
且首句「烧脑的来了」5 字才进入正题，真正的钩子「六个数，两种排法…」落在 1.2 s 之后。这会导致
「钩子 3 秒内抛出」这条铁律在配音对轴后被顶开。建议加校验（见 §8 检查单）。

## 1. 「前 3 秒」钩子模板（12 条，全部 ≤13 字，3 秒内可念完）

> 约束来源：3 秒硬钩子 + 4.2 字/秒 → **钩子主句 ≤ 12.6 字**，取 **≤13 字**。
> 结构依据：有赞把开头钩子分为 痛点型 / 数据权威型 / 悬念反转型 / 情感共鸣型 / 价值预告型（[来源](https://www.youzan.com/cms/article/69295.html)）；
> 这里按任务要求重排为 5 组，并全部写成**可填空的句式骨架**（`{X}` 为槽位，方括号给出取词规则）。

### A. 反常识（认知缺口）
1. `{常识} 其实是错的` — `[常识]=大家默认的做法，如"多练就快"]`
2. `{A} 比 {B} 慢，反了` — `[A/B]=两个同级概念，如"冒泡/选择"]`
3. `都不信：{结论} 是假的` — `[结论]=与直觉相反的断言，≤6 字`

### B. 数字冲击
4. `{数字} 秒，看懂 {概念}` — `[数字]=3/5/10；[概念]≤5 字`
5. `{数字} 个数，差 {倍数}` — 例：`6 个数，差 2 倍`
6. `{百分比} 的人都想错了` — `[百分比]=90%/95%，需与内容一致，避免"绝对化"红线`

### C. 提问
7. `你有没有想过：{现象}？` — `[现象]≤7 字`
8. `为什么 {A} 打不过 {B}？` — `[A/B]≤4 字`
9. `{场景} 时，你选哪个？` — `[场景]≤5 字`

### D. 代价恐惧
10. `{做法}，正在拖慢你` — `[做法]≤6 字，如"死记公式"`
11. `这一步错，全盘都错` — 固定句，适配"关键步骤"类题材

### E. 身份代入
12. `{身份} 必看：{概念} 这样记` — `[身份]=程序员/考研党/家长；[概念]≤5 字`

**落地写法**（`content.json`，hook 镜）：
```json
{"id": "hook", "mood": "hook", "min_dur": 4.6,
 "narration": "6 个数，差 2 倍。为什么？"}
```
- 首句 = 钩子（≤13 字），第二句 ≤8 字（追问/加压），合计 ≤21 字 → 4.6–5.0 s，第 1 个 3 秒内钩子已讲完。
- 禁止在 hook 里出现：「大家好」「今天我们来聊聊」「这个视频讲」（有赞原文点名"避免废话开头"）。

## 2. 分镜节奏表（镜头数 / 每镜秒数 / 字幕字数上限 / 语速区间）

字幕容量推导（对应当前 `SceneAPI.caption(img, s, y=1645, size=50)`）：
- 画布 1080 px，左右安全边距 72 px → 可用 **936 px**；
- `size=50` 的中文字宽 ≈ 50 px → **每行 ≤ 18 字**，取 **16 字/行**留高亮余量；
- 字幕卡最多 **2 行** → **单镜字幕 ≤ 32 字**；`narration` 建议 **≤ 38 字**（含标点）。

### ≈32–40 秒版（5 镜，与现仓库五段式一一对应）

| # | 镜头 id | mood | 建议 rate | 秒数 | narration 字数 | 信息点 |
|---|---|---|---|---|---|---|
| 1 | hook | `hook` | +10~+14% | 3.2–5.0 | ≤21（首句≤13） | 1 个悬念 |
| 2 | rule | `rule` | +2~+4% | 5.0–6.5 | 21–27 | 1 个定义 |
| 3 | insight | `explain` | −3~−4% | 7.0–9.0 | 29–38 | 1 个关键观察 |
| 4 | reveal | `reveal` | +5~+6% | 6.0–7.5 | 25–32 | 1 个结论/反转 |
| 5 | solve | `win` | +10~+12% | 7.0–9.0 | 29–38 | 1 个方法 + 1 个行动 |

合计 ≈ 28.2–37 s（+ 每镜 `lead_in 0.15` / `tail 0.55` → 实际 31.7–40.5 s）。
**要到 45–60 s 就加镜，不要加字数**：每多 5 s 加一个 21–25 字的信息镜。

### ≈45–58 秒版（7 镜，推荐用于"科普天花板"；要到 60–75 s 再加 1–2 个 21–25 字的信息镜）

| # | 镜头 id | mood | 秒数 | 字数 | 作用 |
|---|---|---|---|---|---|
| 1 | hook | hook | 3.2–5.0 | ≤21 | 钩子 |
| 2 | rule | rule | 5.0–6.5 | 21–27 | 定义/规则 |
| 3 | case | explain | 6.0–8.0 | 25–33 | 反例（错在哪） |
| 4 | insight | explain | 7.0–9.0 | 29–38 | 原理 |
| 5 | demo | rule | 7.0–9.0 | 29–38 | 逐步演示 |
| 6 | reveal | reveal | 6.0–7.5 | 25–32 | 高潮/公式 |
| 7 | solve | win | 6.0–8.0 | 25–33 | 实战 + 收尾 |

节奏铁律（4 条，可写成校验）：
1. **单镜 ≤ 9.0 s**：超过就要拆镜（图文信息密度下降、划走概率上升）。
2. **单镜 ≤ 38 字**：超过则字幕必须 3 行 → 挤压画面 + 违反 2 行上限。
3. **每镜都要有一次视觉变化**（`caption` 之外的元素变化，如 `ring` 亮起、`bar_chart` 推进）——否则"静态帧"观感等同录屏。
4. **mood 与 rate 绑定**（现仓库 `tts.py` 的 `MOODS` 已有：hook +12%、rule +2%、explain −4%、reveal +6%、win +10%），与上表一致，无需改；但 **`+12%` 会把语速推到 ≈4.7 字/秒**，因此 hook 字数上限要按 4.7 而非 4.2 算（21 字 ≈ 4.5 s）**「经验值，未经证实」**（rate% → 字/秒 的换算是用 240–260 字/分基准线性外推，未跑校准实验）。

## 3. 封面公式（6 套，含 Pillow 参数）

### 3.0 关键事实：小红书**视频封面只有 3:4 / 1:1 / 4:3 三选**
- "视频封面只有三种尺寸可选：横版 4:3，竖版 3:4，正方形 1:1"，且明确建议**选竖版 3:4**（占屏更大）——[如何创作一张高点击的小红书封面](https://www.woshipm.com/marketing/5572030.html)
- 因此封面画布应为 **1080×1440（3:4）**，**不是** 1080×1920；成片本身的 `size` 仍是 `[1080,1920]`。
- 官方还提供封面 A/B 测试：电脑端发布最多上传 **4 张封面**（1 默认 + 3 PK），**10 小时**后按点击率选优（同上）。→ 我们应**一次产出 3 张差异化封面**（同文案不同配色/版式），交给人工上传 PK。

### 3.1 通用绘制基线（所有公式共用）

```python
CANVAS = (1080, 1440)          # 3:4
MARGIN = 72                    # 四周安全边距 px
TITLE_SIZE_MAX = 132           # 主标题上限
TITLE_SIZE_MIN = 84            # 主标题下限（缩略图可读底线）
SUB_SIZE = 58                  # 副标题
STROKE = max(4, size // 18)    # 描边宽度
LINE_SPACING = 1.14            # 行距 = size * 1.14
BG = "#0E1116"                 # 深底（比纯黑更"高级"，避免 OLED 纯黑裁切感）
FG = "#FFFFFF"
ACCENT = "#FF2D55"             # 强调红（对比度 > 4.5:1）
ACCENT2 = "#FFD400"            # 数字高亮黄
```
> 字号下限的推导：发现页卡片在 1080 px 宽下缩到约 320 px 显示（缩放 0.296），84 px → 约 25 px，仍可辨字形。**「经验值，未经证实」**（未做眼动/点击实验）。
> 高点击封面的心理机制：**知觉性好奇**（熟悉的东西陌生化/差异对比）与**知识性好奇**（信息量大，必须点开才看得清），并常用"红圈"标注提升点击——[1篇笔记互动50万+，高点击率封面的原理](https://www.woshipm.com/marketing/5525145.html)

### 3.2 公式 F1｜数字反差大字报
- 文案结构：`【主】{数字}+{结果词}` / `【副】{对象}{代价}`
- 版式：主标题 1 行居中，占画布上 45%，`size=120`；副标题 1 行 `size=58`，颜色 `ACCENT`；底部 160 px 留空。
- 例：主「差 2 倍」副「6 个数，两种排法」
- Pillow：`draw.text((cx, 520), main, font=font(120, bold=True), anchor="mm", fill=FG, stroke_width=8, stroke_fill="#000000")`

### 3.3 公式 F2｜问句钩子 + 答案贴纸
- 结构：主标题是**问句 ≤10 字**，`size=104`，左对齐（`x=MARGIN`），2 行内；
- 右上角圆角矩形贴纸（`rounded_rectangle(xy=(760,96,1008,208), radius=28, fill=ACCENT)`），内写「3 秒看懂」`size=40` 白字。
- Pillow：贴纸先画，再画文字；贴纸不透明度 100%，文字 100%。

### 3.4 公式 F3｜红圈标注（截图式）
- 画面主体放 hook 镜的关键帧（现 `make.py` 已产出 `cover_frame.png`，取 hook 镜 0.75 时刻）；
- 叠加：红色圆环 `ellipse(width=10, outline=ACCENT)`，半径 120–180 px，中心落在"差异点"；
- 右侧 6 字标签（`size=64`，白字 + 红底条 24 px 高）。
- 依据：红圈能显著提升封面点击——[来源](https://www.woshipm.com/marketing/5525145.html)

### 3.5 公式 F4｜左右对比 VS
- 左半 `#0A84FF` 底 / 右半 `ACCENT` 底，各占 540 px；中间白字 `VS`（`size=96`）+ 白描边；
- 两侧各 3–5 字标题 `size=88`，底部标 `{关键差异}`（`size=52`）。

### 3.6 公式 F5｜清单编号
- 左上竖排编号 `01/02/03`（`size=76`，`ACCENT2`）；
- 主标题 ≤8 字 `size=100`，左对齐，行距 1.14；
- 底部 3 个小标签（`size=40`，灰 `#9AA3AE`），标签间 24 px 间距。

### 3.7 公式 F6｜知识性好奇（遮一半）
- 主标题 8–10 字，**关键字用色块高亮**：先 `rectangle(fill=ACCENT2)`，再用深色字 `#111111` 压在上面；
- 其余文字用 `FG` + 70% alpha（`fill=(255,255,255,178)`）；
- 目的：制造"信息在封面外"的缺口，逼迫点开（知识性好奇机制）。

## 4. 标题公式（12 条）+ 话题标签策略

### 4.1 标题硬约束
- **16–20 字**（含标点），前 **12 字**必须装下核心词（发现页标题会被截断）**「经验值，未经证实」**（截断宽度未实测）。
- emoji ≤ 1 个，且不与其他符号连用（emoji 能提高趣味/信息密度，但过量分散注意力）——[小红书笔记标题应该怎么设计](https://www.woshipm.com/copy/6151865.html)
- 数字优先：数字提升可信度、制造紧迫与"可评估价值"（同上）。
- 人群词 / 情绪词 / 痛点词 三件套至少命中一个（同上）。

### 4.2 公式（`{}` 为槽位）
1. `{数字}个{方法}，让{对象}{结果}` → `3个口诀，让矩阵不再算错`
2. `{常识}错了！{对象}其实是{真相}` → `死记公式错了！排序其实在比交换`
3. `{身份}必看：{痛点}的{数字}个解法` → `程序员必看：快排最坏的3个解法`
4. `为什么{现象}？{数字}秒讲清` → `为什么冒泡慢一倍？5秒讲清`
5. `{错误做法}，正在拖坏你的{对象}` → `死记公式，正在拖慢你的算法题`
6. `{A} vs {B}：差在{关键点}` → `冒泡 vs 选择：差在交换次数`
7. `{数字}分钟搞懂{概念}` → `5分钟搞懂矩阵求逆`
8. `{场景}只用这一招` → `面试手撕快排只用这一招`
9. `{结论}，原因只有{数字}个` → `选择排序更快，原因只有2个`
10. `当{场景}，{对象}会{反直觉结果}` → `当数组变大，冒泡会慢成这样`
11. `用{生活类比}看懂{硬概念}` → `用排队打饭看懂时间复杂度`
12. `{概念}：{一句人话翻译}` → `矩阵求逆：把灯全灭的最短路径`

### 4.3 话题标签策略
- **数量：2–5 个**（"一个话题可以选取 2-5 个标签，过多或过少都会影响曝光效果"）——[小红书话题可以选几个标签](https://xueyuan.yixiaoer.cn/article/26396)
- 结构（固定 4 段式，直接拼进文案尾部）：
  1. 大词 1 个：`#科普`（吃泛流量）
  2. 垂类 1–2 个：`#算法` `#程序员`（吃精准流量）
  3. 长尾场景 1 个：`#面试题` `#期末复习`（吃搜索，搜索占比 30%–65%，见 §0）
  4. 自建系列 1 个：`#3分钟看懂算法`（沉淀合集，便于账号权重）
- 禁：话题里放其他平台名/代称（"淘系""京东""抖快""B站""微博"等属导流违规，见 §6）。
- 搜索向优化：标题与话题里的关键词要"自然融入"，"生硬堆砌关键词会触发限流"——[流量机制](https://3g.163.com/news/article/KIMU57Q405566M9N.html)

## 5. 完播 / 互动优化清单（可执行动作）

按 CES 权重（关注×8 > 评论/转发×4 > 点赞/收藏×1）排优先级：

| 优先级 | 动作 | 参数/写法 |
|---|---|---|
| 1 | 结尾给"关注理由" | solve 镜最后一帧固定挂 `caption` 收尾句：`下一条讲{下一个概念}，关注不迷路`（≤18 字，1 行） |
| 2 | 评论钩子 | solve 镜台词里埋**二选一提问**：`你选 A 还是 B？评论区打 1/2` → 评论权重 ×4 |
| 3 | 收藏钩子 | 片尾 2 秒叠 `tag`「建议收藏 ⭐」；并在 insight 镜用"公式/清单"形式呈现（可复用性=收藏动机） |
| 4 | 前 3 秒 2 次视觉变化 | hook 镜内：0.0 s 出大字 → 1.2 s 出 `ring` → 2.4 s 数字滚动（`SceneAPI` 已有 `ring`/`progress_bar`） |
| 5 | 字幕逐词高亮 | `caption(..., emphasis=[关键词], hi_color=ACCENT, hi_scale=1.08)`，每个镜头 1–2 个高亮词 |
| 6 | 每镜留半个信息 | 镜尾最后 6 字不点破，下一镜开头立即兑现（提升 5 s 留存）**「经验值，未经证实」** |
| 7 | 安全区 | 字幕 `y=1645`（现默认）保持；**底部 300 px（y>1620）不放关键画面元素**，避开平台标题/互动区遮挡；顶部 240 px 同样留白 |
| 8 | 首帧=封面 | `cover_frame.png` 已取 hook 0.75 时刻，与 3:4 封面文案保持一致（同一句式），形成"点开后看到同一句"的一致性 |
| 9 | 时长控在 30–90 s | 见 §0 竖版推荐时长；45–60 s 是知识类最佳区**「经验值，未经证实」** |
| 10 | 发布节奏 | 同一系列固定话题标签 + 固定封面模板，便于系统快速识别调性（"调性干净一致的封面，系统识别更快"，[来源](https://www.woshipm.com/marketing/5572030.html)） |

## 6. 红线清单（违禁词 / 绝对化 / 医疗健康 / 平台特有）

> 依据：[小红书违禁词与内容清单（完整版）](https://m.sohu.com/a/949895373_121838863/)、[2026小红书违禁词汇总](https://www.sohu.com/a/982067173_121124358)、[互联网信息服务深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)

1. **极限/绝对化用语**：最、第一、唯一、100%、永久、根治、彻底、无副作用 → 全部禁用；`100%纯棉` 这类需检测报告。
2. **权威背书类**：国家机关推荐、特供、专供、质量免检、中国驰名商标、国际品质、100% 正品。
3. **医疗/功效**：普通商品禁谈"治疗"；食品保健禁暗示疗效。科普视频若涉健康题材，只讲机制不讲疗效。
4. **迷信/夸大**：招财、旺运、开运、转运。
5. **炫富**：年入百万、月入十万、财富自由（标题/正文/字幕都算）。
6. **跨平台导流**：正文、字幕、花字、评论都不可出现其他平台名及代称（淘系、京东、抖快、B站、微博、橙色小软件、小破站…）。
7. **变体词规避同样违规**：用拼音/谐音/符号替代（如 `bai fen bai` 代"百分百"）仍判违规。
8. **非原创判定（对我们最致命）**：选题高度雷同、**笔记框架 50% 以上一致**、口播词**单篇出现 5 次以上完全一致**都可能被判非原创 → 批量生成必须每镜至少 2 处槽位替换 + 标题/封面独立生成，不能"同一模板换数字"。
9. **AI 合成内容标识**：合成人声属"深度合成"，规定第十六/十七条要求在"合理位置、区域进行显著标识" → 成片片尾 + 简介固定加一行：`配音由 AI 合成（edge-tts）`。这是**法规级**要求，不是运营建议。
10. **处罚量级**：账号降权、禁止发布 7 天（[2026违禁词汇总](https://www.sohu.com/a/982067173_121124358)）。
11. 金融理财、教育培训（承诺效果）、医疗健康三类行业词最严，科普选题尽量避开这三类的"效果承诺"表述。

## 7. 一页速查（给 LLM 写 `content.json` 时的系统提示词）

```
钩子：≤13 字，3 秒讲完；禁用"大家好/今天聊聊"。
每镜：≤38 字，≤9 秒；字数/4.2 ≤ 该镜配音秒数。
镜头数：45s 用 5 镜；60-75s 用 7 镜（加镜不加字）。
字幕：每行 ≤16 字，最多 2 行，y=1645，size=50。
封面：1080x1440（3:4），主标题 84-132px，描边 width=size/18，一次出 3 张变体。
标题：16-20 字，前 12 字放核心词，emoji ≤1。
话题：2-5 个 = 1 大词 + 1~2 垂类 + 1 长尾 + 1 自建系列。
红线：无绝对化用语/无疗效/无平台导流/无炫富；片尾标"AI 配音"。
```
