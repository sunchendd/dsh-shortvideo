## 排期规则

1. **同题不连发**：相邻两条尽量不同学科（按学科轮转取件）
2. **强弱交替**：短的、钩子强的排在前面（新号前几条决定推不推）
3. **长短搭配**：短版搏完播，长版养收藏，同周混排
4. 同一选题的长短版放在同一周（互相导流）
