## 1. 18-plane-window：「方角应力高 21 倍」→ **已改为「十倍以上」**

- 圆孔 `Kt = 3` 是精确解（Kirsch，(3−ν)/(1+ν) = 2.93，ν=0.33）✓
- 方角 21 倍来自 Inglis 式 `Kt = 1+2√(a/ρ)`，**只在 ρ≈1 mm 时成立**：
  ρ=0.5 mm→29.3、ρ=2 mm→15.1、ρ=5 mm→9.9、ρ=10 mm→7.3
- 真实舷窗圆角半径通常 ≥5 mm，「21 倍」是尖角极限，不是量产件数值
- **已修**：口播/画面/封面统一改为「十倍以上」（Kt≥10 对应 ρ≤5mm，是机加工尖角的现实范围），
  具体敏感性写进 reveal 的注释与 kernel。旁白、封面、一张图已重渲，score 回到 100

## 2. 17-equal-loudness-bass：「低音少 34 分贝」→ **已用 ISO 226:2003 官方公式复算，成立**

- 片中三组数内部自洽（40 Hz 与 1 kHz 的差随等响级 0.45 dB/方线性变化，60 方插值正好 34）
- 三套数据低频段差异明显：ISO 226 修订报告说 **Robinson–Dadson 与现行标准差达 10–15 dB**，
  而 **Fletcher–Munson 与现行标准吻合更好**（A 计权的 40 phon 曲线也被证实与现代测定一致）
- 片中取 F–M 体系，方向上无误；**具体表值建议以 ISO 226:2003 复核**
- **已复核**：拿到 ISO 226:2003 表 1 的 29 个频点参数（α_f / L_U / T_f），按第 4.1 节公式实算：
  ```
  60 方：1kHz=60.0、100Hz=78.7、40Hz=94.2  ⇒ 18.7 / 34.2 dB   片中 19 / 34 ✓
  80 方：40Hz=105.3                          ⇒ 25.3 dB          片中 25   ✓
  40 方：40Hz=82.6                           ⇒ 42.6 dB          片中 43   ✓
  ```
  **两个体系吻合到 0.5 dB 以内，不需要改片。** 原判断（"版本依赖风险"）偏保守了。
- 复算依据已写进 kernel，refs 增加 ISO 226:2003 表 1 与 PyDSM 实现
