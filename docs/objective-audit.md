## ① 支持 3 款流畅有感情的配音音色

| 音色 | Azure 神经音色 | 人格定位 | 同一句话实测基频（F0 中位） |
|---|---|---|---|
| `xiaoxiao` | zh-CN-XiaoxiaoNeural | 活泼亲切女主，句尾自然上扬 | **235 Hz** |
| `yunxi` | zh-CN-YunxiNeural | 阳光邻家男声，反问句最抓耳 | **157 Hz** |
| `yunjian` | zh-CN-YunjianNeural | 浑厚沉稳男声，留白多压得住悬念 | **108 Hz** |

> 三个音色差 78 / 49 Hz，是听觉上能分辨的三档；以上是**同一句话**的对照测量
> （不同文本的音高不可比），复现：`voice_lab.py` 后用 `analyze()` 逐条测 `/tmp/voices/<preset>/explain.wav`。

**"有感情"落在哪**：每个音色绑定 5 套情绪韵律（`hook/rule/explain/reveal/win`），
实测 `yunxi` 的韵律表是 `hook +16% / rule +7% / explain -1% / reveal +5% / win +13%`——
钩子明显加速、讲解略微放慢，不是全片一个语调。

**证据**
```bash
python skills/shortvideo/tools/voice_lab.py --out /tmp/voices    # 出三音色 × 五情绪试听 + 30 条验收
grep -h '"preset"' examples/*.content.json | sort | uniq -c      # 使用分布：5 / 5 / 4
```
14 条成片里三个音色都在用（xiaoxiao 5、yunxi 5、yunjian 4），不是"支持了但没用"。

## ③ 检索 GitHub 优秀开源代码

📄 [docs/oss-landscape.md](oss-landscape.md) — 132 行，**13 个仓库链接**

结论是"**能借的借，借不到的自己写**"：
- 借：edge-tts（神经配音）、imageio-ffmpeg（免装 ffmpeg）、Pillow（逐帧渲染）

而"科普讲解 + 中文神经配音 + 逐帧可控"这个组合，自己实现反而更可控（单条渲染 83~127 fps）。

## 还差什么（诚实清单）

1. **没有真实发布数据**。CTR / 完播 / CES 全部是"预估达标"，`ab-log.csv` 还是空的。
   爆款与否最终要平台数据说话，这部分只能等真的发出去。
2. **视觉仍是程序化图形**，没有真人文案外的素材（实拍/插画/动效模板）。
   在"信息密度"赛道够用，在"情绪感染"赛道偏弱。
3. **配音是 TTS**，情绪靠韵律参数模拟。真正的人类语感、气口、笑声还做不到。
4. **选题依赖人工判断**（哪怕是角色 skill 在判断），没有"从评论区/搜索词反推选题"的数据闭环。
