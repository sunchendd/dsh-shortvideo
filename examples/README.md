## 1. 01 蒙提霍尔｜数学反直觉

**一句话定位**：所有人都在概率题里"凭感觉对半分"，这条用 1/3 → 2/3 的翻倍结果直接打脸直觉。

**为什么有爆款潜力**
- **反常识强度拉满**：观众的第一反应就是「剩两扇，各一半吧」——这条视频的钩子直接踩在这个错误直觉上（playbook §1-A 反常识组）。
- **人群大且刚需**：概率题是面试/考研/游戏抽卡的公共话题，搜索流量占比 30%–65%（playbook §0），「蒙提霍尔」本身是高频搜索词。
- **强可视化**：画面只需要「三扇门 + 概率条 1/3 vs 2/3 + 换门后条翻倍」，`SceneAPI.bar_chart` / `ring` 就够，零素材依赖。
- **钩子合规且短**：首句「三扇门只有一辆车」8 字，落在 1.9 s（8÷4.2），远早于"前 3 秒"红线（playbook §0：70% 用户前 3 秒决定去留）。
- **完播结构**：5 镜总估时 ≈38 s，落在 30–90 s 推荐区间的前段（playbook §0），单镜最长 9.0 s（卡在上限），无"拖时长"镜。
- **互动设计**：solve 镜第一句就是「记住一句话：换」，天然引出评论区站队（换/不换），评论 CES 权重 ×4（playbook §0）。

**5 条候选标题**（均已校验 16–20 字，前 12 字含核心词）
1. 换还是不换？九成人的第一反应都是错的（17 字）
2. 三扇门只开一扇空门，概率为什么不是各一半（19 字）
3. 概率题必看：蒙提霍尔问题3秒就能讲明白（18 字）
4. 三分之一还是三分之二，这道题骗了无数人（18 字）
5. 面试被问到蒙提霍尔问题，你就这么回答（17 字）

**话题标签**（2–5 个，1 大词 + 2 垂类 + 1 长尾 + 1 自建系列，见 playbook §4.3）
`#科普` `#概率` `#逻辑思维` `#面试题` `#3分钟看懂数学`

**封面块**（`cover`）：kicker「反常识概率」/ headline `换门` `还是守门` / highlight「换门」/ sub「三扇门只剩两扇，概率却偏了一半」/ cta「答案在最后 3 秒」/ serial `01`

## 2. 02 瑞利散射｜生活物理

**一句话定位**：把「天空本来就是蓝的」这个日常错觉，换成「蓝光被空气撞散了近六倍」的可算结论。

**为什么有爆款潜力**
- **反常识钩子 + 立刻给答案**：首句「天空本来是黑的」7 字（1.7 s 落地），制造缺口；第二句马上兑现「蓝是空气撞出来的」——符合「钩子 3 秒内抛出、不给答案只说一半」的写法（playbook §1-A/§1-B）。
- **人群最大**：抬头就能验证的现象，没有知识门槛；家长/学生/摄影党都会点。
- **强可视化 + 可算**：`insight` 镜讲「四次方反比」，`reveal` 镜直接给两个波长的对比条（450 nm vs 700 nm），算例 (700/450)⁴ = **5.86 ≈ 近六倍**，是视频里唯一需要观众"看见"的数字。
- **封面即结论**：3:4 封面大字「天空的蓝 / 是空气 / 撞出来的」，highlight 落在「撞出来的」——知识性好奇型封面（playbook §3.7）——点开前就知道要拿一个反直觉结论。
- **系列化**：cta 与 solve 镜都指向「晚霞为什么是红的」，同一物理量（光程）复用，天然做成第二集（关注 CES 权重 ×8，playbook §0）。
- **时长安全**：≈37 s，5 镜，最长镜 9.0 s；文案 133 字 = 约 31.7 s 口播（4.2 字/秒口径），落在 240–260 字/分的正常语速区间（playbook §0）。

**5 条候选标题**
1. 天空本来一片漆黑，蓝是空气撞出来的（16 字）
2. 蓝光比红光强近六倍，所以抬头看见的是蓝（18 字）
3. 为什么天是蓝的，晚霞又为什么是红的（16 字）
4. 阳光进大气后发生了什么，5分钟给你讲透（18 字）
5. 物理启蒙：一次撞击就决定了天空的颜色（17 字）

**话题标签**
`#科普` `#物理` `#天空` `#涨知识` `#3分钟看懂物理`

**封面块**：kicker「生活物理」/ headline `天空的蓝` `是空气` `撞出来的` / highlight「撞出来的」/ sub「蓝光散射比红光强近六倍」/ cta「下条讲晚霞」/ serial `02`

**科学内核**（已算）：

## 3. 03 浮点数｜计算机原理

**一句话定位**：所有人第一次撞见 `0.1+0.2=0.30000000000000004` 都会以为电脑坏了，这条讲清"错在第 17 位小数"。

**为什么有爆款潜力**
- **天然爆点是"数字本身"**：`0.30000000000000004` 是可以直接怼在画面上的视觉冲击，属于 playbook §1-B 数字冲击型钩子。
- **人群精准且高互动**：程序员/学生/Excel 用户；「踩坑」类内容天然带评论区（"我们项目就因为等号比浮点炸过"），评论 CES ×4、转发 ×4。
- **强可视化**：二进制尾数截断 → 误差累积 → 第 17 位露头，三步都在 `SceneAPI` 能力内（逐格浮现 + 位数高亮 + 对比条）。
- **给出可执行结论**：solve 镜直接给「别用等号，给容差 1e-9」，收藏动机强（收藏率 ≥3% 是第二池晋级线，playbook §0）。
- **合规安全**：纯技术事实，无医疗、无绝对化表述；"电脑算错了？"是设问，答案是否定，不构成虚假陈述。
- **节奏**：5 镜 ≈37.2 s；最长镜 9.0 s（正好卡在上限，信息量最大的一镜），其余 ≤8.6 s；文案 138 字。

**5 条候选标题**
1. 零点一加零点二，为什么算出来不等于零点三（19 字）
2. 0.1+0.2 不等于 0.3，电脑真的算错了？（20 字）
3. 程序员必看：浮点数为什么不能用等号比较（18 字）
4. 误差藏在第十七位小数，你可能一直不知道（18 字）
5. 连 0.3 都存不下，浮点数到底发生了什么（18 字）

**话题标签**
`#科普` `#程序员` `#浮点数` `#踩坑` `#3分钟看懂计算机`

**封面块**：kicker「计算机原理」/ headline `0.1+0.2` `不等于` `0.3` / highlight「0.1+0.2」/ sub「二进制存不下这些小数」/ cta「别用等号比较」/ serial `03`

> 封面 headline 第一行 `0.1+0.2` 是半角字符，按视觉宽度算 **3.5 字宽**（全角口径 ≤6 字，见 §5 口径说明），仍在大字可读范围内。

**科学内核**（已跑）：
```
python: repr(0.1+0.2) = '0.30000000000000004'
format(0.1+0.2, '.20f') = 0.30000000000000004441 → 第 17 位小数开始出现 4
双精度尾数 52 bit，0.1 的二进制是无限循环 → 必须截断
```

## 5. 自检口径与汇总结果

**口径**（下表全部按这个口径算，可复算）：
- `字数` = `len(re.sub(r"\s", "", narration))`，**含标点**（TTS 会为标点停顿时长，按含标点算更保守）；
- `字数÷4.2` = 按 4.2 字/秒（240–260 字/分 的中值偏快档）折算的口播时长；
- `估时` = `max(min_dur, 字数÷4.2 + lead_in + tail)`，与 `make.py` 的 `dur = max(min_dur, adur + lead + tail)` 同构；
- 区间上界 `估时_hi` 按 `字数÷4.2 × 1.08 + 0.7` 估（留 8% 的 TTS 慢读余量）；
- 封面 headline 用**字宽**口径：全角 1、半角 0.5（大字排版看视觉宽度）。

## 7. 维护须知

- **改文案后必须重算**：任一句改动都会破坏 `字数÷4.2 ≤ min_dur` 与"每分句≤16 字"，两项任一跳红，字幕就会折行或配音超时而挤压下一镜。
- **`min_dur` 不要随手往小改**：它同时是"最短停留"，也是数字校验的分母；往下调只会在真实 TTS 时长更长时被 `max()` 吃掉，白改。
- **`emphasis` 只能取分句内连续子串**（例：「蓝光散射比红光强近六倍」里取「近六倍」，不能取「蓝光…强」）。
- **封面 `highlight` 必须在 headline 某一行里出现**，否则 `cover.py` 静默不高亮。

### 9.2 08 冰为什么滑｜材料 / 表面物理

**一句话定位**：把"冰刀把冰压化了"这句流传一百多年的解释当场算死——**压力只能把冰点压低 0.1 度，真正让你滑的是冰表面自己长出来的那层水膜**。

**为什么有爆款潜力**
- **钩子踩的是一个全民都信的错误解释**：首句「冰刀压下去」5 字（1.2 s 落地），紧跟「冰点只降 0.1 度」——观众的第一反应是"不对吧，那为什么这么滑"，认知缺口立刻成立（playbook §1-A 反常识组）。
- **数字够狠且能复算**：1.3 兆帕 → 0.1 度；要压化 −10 ℃ 的冰得 135 兆帕，等于**6 平方厘米上压 8 吨**。8 吨这个量级谁都懂，冰刀早断了。
- **"原来如此"是"你脚下一直有一层水"**：预熔（premelting）水膜在 −10 ℃ 依然存在，摩擦只补一点点热就够厚——一句话解释"越冷越涩"这个日常经验。
- **强可视化**：`formula` 把 785 N ÷ 6 cm² = 1.3 兆帕 摆出来，`stat` 打"8 吨"，`flow` 走"最外层分子→水膜→润滑层"。
- **合规安全**：只讲热力学与摩擦学机制，不涉及任何"防摔/护具/训练效果"类功效话术（playbook §6.3）。

**5 条候选标题**（均已校验 16–20 字）
1. 冰刀压下去冰点只降0.1度，那靠什么滑（19 字，`publish_title`）
2. 冰不是被压化的，它表面本来就有一层水膜（19 字）
3. 零下十度的冰照样滑，压力只解释那0.1度（20 字）
4. 滑冰场的物理：压不化的冰为什么这么滑（18 字）
5. 零下十度的冰要压化，得在6平方厘米压8吨（20 字）

**话题标签**：`#科普` `#物理` `#滑冰` `#冷知识`（4 个）

**封面块**（`cover`）：kicker「材料反常识」/ headline `压不化冰` `为什么还滑` / highlight「压不化」/ sub「冰刀压上去，冰点只降 0.1 度」/ cta「脚下有层水」/ serial `08`

**科学内核**（已跑验证；口径写在镜头里，避免"没交代假设"）
```
克拉珀龙方程（冰-水，0 ℃）：dT/dP = T·Δv / L
  比容：冰 1.090750 L/kg，水 1.000200 L/kg → Δv = -9.055e-5 m³/kg
  T = 273.15 K，L = 333.55 kJ/kg → dT/dP = -7.415e-8 K/Pa
  → 每 1 兆帕 -0.074 度；每 1 标准大气压 -0.0075 度
滑冰者：80 kg = 785 N；两只冰刀接触 6 cm² = 6e-4 m² → 1.31 兆帕 = 12.9 大气压
  熔点降低 = 1.31 × 0.074 = 0.097 度 → 视频说 0.1 度
要压化 -10 ℃ 的冰：需 10 / 0.074 = 135 兆帕 = 1331 大气压
  压在 6 cm² 上 → 81 kN = 8.2 吨 → 视频说 8 吨
融出 1 微米厚水膜：6e-4 m² × 1e-6 m × 917 kg/m³ × 3.34e5 J/kg = 0.18 J（很小）
机制：冰面最外层分子只有一半邻居 → 预熔出纳米级准液层（-10 ℃ 仍在）→ 摩擦再补一层水 → 冰刀近乎浮滑
```

### 9.3 09 记忆重写｜认知心理 / 记忆

**一句话定位**：把"我记得很清楚"翻译成"我又重写了一遍"——**同一段视频，只换提问里的一个动词，就多出三成"看见碎玻璃"的人**。

**为什么有爆款潜力**
- **钩子是一个"不存在的物证"**：首句「三成的人」4 字（1 s 落地），紧跟「记住了一地碎玻璃。其实一片都没有」——观众会本能地回想"我有没有记错过"（playbook §1-A 反常识组 + 自检动作）。
- **实验可复述、数字可复算**：Loftus & Palmer (1974) 的两个结果都只有两位数——车速 40.8 对 31.8 英里/时（差 9 英里，28%）、碎玻璃 32% 对 14%（2.3 倍）。观众能自己验算。

- **可执行动作**：solve 给的是"先写下来，再讨论"（别让别人的用词先进入你的记忆），是能立刻用的一条。
- **合规安全**：讲认知机制与实验方法，不做任何"提高记忆力/改善睡眠"类功效承诺，也不碰司法的具体个案（playbook §6.3/§6.11）。
